# Coffee Grounds Keeper

Coffee Grounds Keeper 是一个正在开发中的咖啡渣管理系统，目标是在 Linux 开发板上完成咖啡渣状态检测、分类判断和信息展示。

## 最终成品效果

成品运行在 i.MX6ULL 等 Linux 开发板上，连接温湿度传感器、显示屏以及风扇、水泵、电机或舵机等执行器后，可以呈现以下效果：

- 自动读取咖啡渣附近的温度和湿度。
- 根据湿度判断咖啡渣状态，例如偏干、偏湿或正常。
- 根据用户选择的模式，显示当前干燥或发酵处理状态。
- 在显示屏上展示当前温度、湿度、处理模式、咖啡渣状态和系统状态。
- 支持咖啡渣处理相关教程或说明视频播放。
- 后续可控制风扇辅助干燥，控制水泵辅助加水发酵。
- 后续可通过电机或舵机完成基础分类、投放或机构动作。
- 传感器异常、配置错误或设备异常时，系统给出错误提示而不是直接崩溃。

最终使用场景示例：

```text
当前温度：28.4 C
当前湿度：62.5 %
处理模式：发酵模式
咖啡渣状态：偏干
系统状态：加水/发酵中
```

## 当前开发状态

项目目前还在早期开发阶段。

当前已完成部分接口：

- 模拟温湿度传感器 `MockSensor`
- 终端显示模块 `TerminalDisplay`
- 传感器读取失败模拟
- 温度、湿度、模式、系统状态的终端输出
- 基础 CMake 构建

当前运行效果：

```text
Temperature: 24.93 C
Humidity: 39.26 %
Mode: Dry
State: Checking
```

传感器读取失败时：

```text
[Error] Sensor read failed
```

## 构建运行

```bash
cmake -S . -B build
cmake --build build
./build/coffee-grounds-keeper
```
